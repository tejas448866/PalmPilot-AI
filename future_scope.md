# Future scope

These items are not implemented: a custom-trained gesture classifier, face/head or eye
tracking, voice commands, adaptive sensitivity, user profiles, a graphical settings
tool, telemetry analytics, ML gesture recognition, and a broader profile library.
They are optional extensions, not requirements of the current threshold-based system.

The `GameProfile` protocol is ready for data-driven Euro Truck, Forza, and Need for
Speed mappings, but those profiles are not claimed as tested or bundled.
